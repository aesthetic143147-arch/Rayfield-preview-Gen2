Rayfield, in two columns.

Rayfield Columns is Rayfield Gen2 with every tab split into a left and a right column. The elements, animations and API are the ones you already know.

Getting started#

Load the library in your script with one line.

local Rayfield = loadstring(game:HttpGet("https://raw.githubusercontent.com/aesthetic143147-arch/Rayfield-preview-Gen2/main/dist/RayfieldColumns.luau"))()

Then make a window, add a tab, and fill its two columns.

local Window = Rayfield:CreateWindow({
    name = "Omnity",
    configuration = { autoSave = true, autoLoad = true, fileName = "Omnity" },
})

local Main = Window:CreateTab({ name = "Main", icon = 84750991656135 })

Main.Left:CreateSection({ name = "Farming" })
Main.Left:CreateToggle({
    name = "Auto Farm",
    callback = function(enabled)
        print("Auto Farm:", enabled)
    end,
})

Main.Right:CreateSection({ name = "Settings" })
Main.Right:CreateSlider({ name = "Speed", range = { 16, 100 }, value = 16 })

Press K to show or hide the window. Players can pick a different key on the settings page, behind the cog in the title bar.

Rayfield Columns is fan-made. It's built on Rayfield Gen2 by Sirius, who don't make or support it. See credits.

Window#

Create one window per script. Everything else hangs off it.

local Window = Rayfield:CreateWindow({
    name = "Omnity",
    subtitle = "Bloxburg",
    sidebarLayout = false, -- true puts the tabs in a rail on the left
    configuration = {
        autoSave = true,
        autoLoad = true,
        fileName = "Omnity",
    },
})
OptionTypeWhat it does
namestringTitle in the top bar.
subtitlestringSmall line under the title.
iconnumberImage asset id next to the title.
sidebarLayoutbooleanTabs in a rail on the left instead of across the top.
scalenumberDraw the window at a fixed size, like 0.8. Leave it out to scale automatically: phones get a smaller window with more room inside, PCs stay at full size.
configurationtableautoSave, autoLoad, fileName, customFolder. See saving.
themestring or tableA built-in theme name, or a table of colours to change. Default when left out. See theming.
showName, showIconstring, numberWhat the collapsed pill shows while the window is hidden.
showIconOnlybooleanCollapse to a round icon instead of a pill.
locale, translationsstring, tableSee localization.

Window methods

MethodWhat it does
Window:Show(), Hide(), ToggleHide()Open or collapse the window.
Window:Navigate("Main")Switch to a tab by name or by its handle.
Window:Unload()Remove the window and everything in it.
Window.unloadedtrue once unloaded. Use it to stop your loops.

Tabs#

A tab needs a name, an icon, or both. The first tab you create opens on its own.

local Main = Window:CreateTab({ name = "Main", icon = 84750991656135 })
local Home = Window:CreateTab({ icon = 93364949241311 }) -- an icon on its own

Icons are Roblox image asset ids. Tab:Select() opens a tab and Tab:Remove() deletes it.

Columns#

Every tab has two columns, Tab.Left and Tab.Right. Any element can go in either one.

Main.Left:CreateToggle({ name = "On the left" })
Main.Right:CreateToggle({ name = "On the right" })

You can also create on the tab and pick a side. Without side, the element goes left, so scripts written for regular Rayfield keep working.

Main:CreateToggle({ name = "Goes left" })
Main:CreateToggle({ name = "Goes right", side = "Right" })

local Right = Main:GetColumn("Right") -- 1 and 2 work too
  • The columns sit side by side and scroll together.
  • On narrow screens they stack, left first. The Phone switch above the preview shows this.
  • A tab that only uses one column gets the full width.

Section#

A small heading inside a column, like Job and Breaks in the preview.

Main.Left:CreateSection({ name = "Farming" })

Text#

A card with a title, a body, or both.

local Status = Main.Left:CreateText({ name = "Status", text = "Waiting" })

Status:Set("Running")      -- change the body
Status:SetTitle("Farming") -- change the title

Divider#

Main.Left:CreateDivider()                               -- a plain line
Main.Left:CreateDivider({ text = "or" })                -- a line with a word
Main.Left:CreateDivider({ line = false, spacing = 20 }) -- empty space

Group#

Puts buttons, toggles, stats or sliders side by side in one row.

local Row = Main.Right:CreateGroup()

Row:CreateButton({ name = "Save", callback = function() end })
Row:CreateButton({ name = "Load", callback = function() end })

Pass { direction = "column" } for a vertical group, which can also hold dropdowns, sections, text and dividers.

Button#

Main.Left:CreateButton({
    name = "Go To Work",
    callback = function()
        print("clicked")
    end,
})
OptionWhat it does
nameThe label.
descriptionAn optional line under the button.
iconAn optional image asset id.
callbackRuns on click.

Toggle#

local AutoFarm = Main.Left:CreateToggle({
    name = "Auto Farm",
    value = false,
    callback = function(enabled)
        print(enabled)
    end,
})

AutoFarm:Set(true)
print(AutoFarm.value)
OptionWhat it does
nameThe label.
valueStarting state. Off by default.
description, iconOptional.
flagThe key it saves under. Defaults to the name without spaces.
forgetStatetrue to never save it.
callback(value)Runs with the new state.

Slider#

local WorkTime = Main.Right:CreateSlider({
    name = "Work Time",
    range = { 5, 120 },
    increment = 5,
    value = 30,
    suffix = "min",
    callback = function(value, dragging)
        print(value)
    end,
})

WorkTime:Set(60)
OptionWhat it does
range{ min, max }.
incrementStep size. 1 by default.
valueStarting value.
suffixText after the number, like "min" or "%".
minimalOnly the bar, without the label.
callback(value, dragging)dragging is true while the handle is held.

Dropdown#

local Job = Main.Left:CreateDropdown({
    name = "Select Job",
    options = { "Baker", "Cashier", "Delivery" },
    value = "Baker",
    callback = function(option)
        print(option)
    end,
})

Job:Set("Cashier")
Job:Refresh({ "Baker", "Cashier", "Miner" }) -- replace the options
Job:Add("Janitor")
Job:Remove("Miner")

With multiSelect = true, the value is a list and the callback receives a list.

Main.Left:CreateDropdown({
    name = "Modules",
    options = { "ESP", "Tracers", "Chams" },
    multiSelect = true,
    value = { "ESP" },
    placeholder = "None selected",
    callback = function(selected)
        print(table.concat(selected, ", "))
    end,
})

Input#

Main.Left:CreateInput({
    name = "Player Name",
    placeholder = "Enter a name",
    callback = function(text)
        print(text)
    end,
})

numeric = true accepts numbers only, and clearOnFocus = true empties the box when it's clicked. The callback runs on Enter or when the box loses focus.

Keybind#

Main.Right:CreateKeybind({
    name = "Sprint",
    value = Enum.KeyCode.LeftShift,
    callback = function(key)
        print("pressed", key)
    end,
})

-- hold mode: true while held, false on release
Main.Right:CreateKeybind({
    name = "Zoom",
    value = Enum.KeyCode.C,
    hold = true,
    callback = function(holding)
        print(holding)
    end,
})

Color picker#

Main.Right:CreateColorPicker({
    name = "Highlight",
    color = Color3.fromRGB(235, 90, 215),
    callback = function(color, alpha)
        print(color, alpha)
    end,
})

color also takes a hex string. alpha, from 0 to 1, sets the starting opacity.

Stat#

A card with a number and how much it changed, like Shift Earnings in the preview.

local Earnings = Main.Right:CreateStat({
    name = "Shift Earnings",
    prefix = "$",
    value = 349,
})

Earnings:Set(Earnings.value + 50)

Other options: suffix; compact for a smaller card; display = "change" to show the change instead of the value on a compact card; changeMode = "absolute" to show the difference instead of a percentage.

Progress#

local Download = Main.Right:CreateProgress({
    name = "Download",
    range = { 0, 100 },
    value = 35,
})

Download:Set(80)
Download:SetText("Almost done")

Main.Right:CreateProgress({ name = "Setup", steps = 5, value = 2 })    -- in segments
Main.Right:CreateProgress({ name = "Loading", indeterminate = true }) -- a looping sweep

Console#

A scrolling box of text for logs.

local Log = Main.Right:CreateConsole({
    name = "Console",
    height = 120,
    follow = true, -- stay on the newest line
})

Log:Append("[12:00] started")
Log:Clear()
Log:Copy() -- copies to the clipboard where the executor allows it

Chat#

A live chat room backed by a channel in your Discord server. Players chat, share server invites and send emoji; your community answers from Discord, and deleting a message on Discord removes it for everyone.

Main.Right:CreateChat({
    name = "Community",
    endpoint = "https://your-relay.example.com",
    channel = "general",
    height = 280,
    onMessage = function(message)
        print(message.author.name, message.content)
    end,
})

The chat talks to a small relay you run (the relay/ folder). The relay holds your bot token, so it never ends up in a script anyone can read. It also rate-limits players, blocks mass pings, and lets moderators ban with !chatban <robloxId>. Setup takes about ten minutes: follow its README.

Methods: Send(text), Refresh(), SetChannel(name), Clear(), Remove().

Nameplates#

An animated nameplate over the head of everyone running your script, in the Omnity look by default: the Omnity mark rocking gently in a soft halo with sparks orbiting it, and a dark glass card over a spiral galaxy. It enters in stages (mark, card, title, name, badge), then bobs, breathes and catches the light.

local Plates = Window:CreateNameplate({
    title = "OMNITY",
    badge = "Developer",
    endpoint = "https://your-relay.example.com", -- to see other users' plates
})

-- every part of the look is a setting
Plates:SetStyle({ accent = Color3.fromRGB(255, 90, 160), sparkles = 4, entrance = "fade" })
Plates:SetStyle("Midnight") -- presets: Omnity, Midnight, Mono

Settings cover shape (size, lift, cornerRadius), colour (accent, cardColor, titleColor…), images (logo, backdrop, each an asset id, URI or false), fonts, and every motion (logoSway, sparkles, sweep, bob…). The README lists them all.

Without endpoint you see your own plate only. With it, players check in with the relay and see everyone else in the same server who runs the script.

Notifications#

Window:Notify({
    title = "Saved",
    content = "Your settings were saved.",
    duration = 5,
    icon = 125823673784681,
})

duration is optional. Without it, longer messages stay on screen longer.

Toasts#

A short message at the top or bottom of the screen.

Window:Toast({ title = "Heading to work" })
Window:Toast({ title = "Saved", subtitle = "Omnity", position = "Bottom" })

Popups#

Window:Popup({
    title = "Reset everything?",
    content = "This can't be undone.",
    options = {
        { text = "Cancel" },
        { text = "Reset", style = "danger", callback = function()
            print("reset")
        end },
    },
})

Button styles are "neutral" (the default), "primary" and "danger".

Tags#

Small badges next to the window title, like Bloxburg in the preview.

Window:CreateTag({ text = "Bloxburg", color = Color3.fromRGB(235, 90, 215) })

Locking#

Buttons, toggles, sliders, dropdowns, inputs, keybinds and color pickers can be locked. A locked element dims, ignores clicks and never runs its callback. The reason replaces its description until you unlock it.

AutoFarm:Lock("Needs a premium key")
AutoFarm:Unlock()
print(AutoFarm:IsLocked())

Saving and flags#

Turn on configuration in CreateWindow and values save by themselves. Each element saves under its flag, which defaults to its name without spaces, so Work Time saves as WorkTime.

print(Window.Flags.WorkTime)   -- read a saved value
Window.Flags.WorkTime = 60      -- set it: the UI updates and the callback runs

Window:Save("PvP")              -- save a named config
Window:Load("PvP")
print(Window:ListConfigs())

Files are stored in RayfieldColumns/Configurations. Players can save and load configs from the settings page too.

Theming#

Rayfield Columns ships the same six themes as Rayfield Gen2. Default is used unless you pick another one. The chips above the preview show each of them.

ThemeLook
"Default"Graphite with a green accent.
"Amethyst"Deep violet with a purple accent.
"Cobalt"Navy with a blue accent.
"Ember"Warm charcoal with an orange accent.
"Frost"Light, with a cyan accent.
"Rose"Dark plum with a pink accent.

Players can also pick any of them from the Theme dropdown on the settings page (the cog in the title bar). Their pick is remembered next time.

Pick one in your script when you create the window, or switch at any time:

local Window = Rayfield:CreateWindow({ name = "Omnity", theme = "Cobalt" })

Window:ChangeTheme("Rose")

To use your own colours, pass a table with only the keys you want to change. Everything else comes from Default.

Window:ChangeTheme({
    AccentColor = Color3.fromRGB(235, 90, 215),
    SliderProgress = Color3.fromRGB(235, 90, 215),
})

Localization#

Add translations by language code, using the English text as the key. Anything you leave out stays in English.

local Window = Rayfield:CreateWindow({
    name = "Omnity",
    translations = {
        fr = { ["Auto Farm"] = "Farm auto" },
    },
})

Window:SetLocale("fr")
