Rayfield Columns

A two-column edition of Rayfield Gen2. Same elements, same API, but every tab has a left and a right column.

Fan-made and unofficial. Built on Rayfield Gen2 by Sirius, not made or supported by them. See credits.

Load the library

local Rayfield = loadstring(game:HttpGet("https://raw.githubusercontent.com/aesthetic143147-arch/Rayfield-preview-Gen2/main/dist/RayfieldColumns.luau"))()

Your first window

local Rayfield = loadstring(game:HttpGet("https://raw.githubusercontent.com/aesthetic143147-arch/Rayfield-preview-Gen2/main/dist/RayfieldColumns.luau"))()

local Window = Rayfield:CreateWindow({
    name = "Pulse",
    configuration = { autoSave = true, autoLoad = true, fileName = "Pulse" },
})

local Main = Window:CreateTab({ name = "Main", icon = 84750991656135 })

Main.Left:CreateSection({ name = "Farming" })
Main.Left:CreateToggle({
    name = "Auto Farm",
    callback = function(enabled)
        print("Auto Farm:", enabled)
    end,
})

Main.Right:CreateSection({ name = "Settings" })
Main.Right:CreateSlider({ name = "Speed", range = { 16, 100 }, value = 16 })

Press K to show or hide the window. Players can change that key on the settings page (the cog in the title bar).

Window

Create one window per script. Everything else is built on it.

local Window = Rayfield:CreateWindow({
    name = "Pulse",
    subtitle = "Bloxburg",
    sidebarLayout = false, -- true puts the tabs in a rail on the left
    configuration = {
        autoSave = true,
        autoLoad = true,
        fileName = "Pulse",
    },
})
OptionTypeDescription
namestringTitle shown in the top bar.
subtitlestring?Small line under the title.
iconnumber?Asset id shown next to the title.
sidebarLayoutboolean?Tabs in a left rail instead of across the top.
configurationtable?autoSave, autoLoad, fileName, customFolder. See Saving.
themestring | table"Default" or a table of overrides. See Theming.
showName, showIconstring, numberWhat the collapsed pill shows while hidden.
showIconOnlyboolean?Collapse to a round icon instead of a pill.
locale, translationsstring, tableSee Localization.

Methods

MethodDescription
Window:Show() / Hide() / ToggleHide()Open or collapse the window.
Window:Navigate("Main")Switch to a tab by name or handle.
Window:Unload()Destroy the window and everything in it.
Window.unloadedtrue once unloaded. Handy for ending loops.

Tabs

A tab needs a name, an icon, or both. The first tab opens automatically.

local Main = Window:CreateTab({ name = "Main", icon = 84750991656135 })
local Home = Window:CreateTab({ icon = 93364949241311 }) -- icon only

Icons are Roblox image asset ids. Tab:Select() opens a tab, Tab:Remove() deletes it.

Columns

Every tab has two columns: Tab.Left and Tab.Right. Every element can go in either one.

Main.Left:CreateToggle({ name = "On the left" })
Main.Right:CreateToggle({ name = "On the right" })

You can also create on the tab and pick a side. Without side, elements go left, so old Rayfield scripts keep working.

Main:CreateToggle({ name = "Goes left" })
Main:CreateToggle({ name = "Goes right", side = "Right" })

local Right = Main:GetColumn("Right") -- also accepts 1 or 2
  • Columns sit side by side and scroll together.
  • On narrow screens (phones) they stack: left first, then right.
  • If a tab only uses one column, it takes the full width.

Section

A small heading inside a column.

Main.Left:CreateSection({ name = "Farming" })

Text

A card with a title, a body, or both.

local Status = Main.Left:CreateText({ name = "Status", text = "Waiting" })

Status:Set("Running")      -- change the body
Status:SetTitle("Farming") -- change the title

Divider

Main.Left:CreateDivider()                   -- a plain line
Main.Left:CreateDivider({ text = "or" })    -- a line with a word
Main.Left:CreateDivider({ line = false, spacing = 20 }) -- empty space

Group

Puts buttons, toggles, stats or sliders side by side in a row.

local Row = Main.Right:CreateGroup()

Row:CreateButton({ name = "Save", callback = function() end })
Row:CreateButton({ name = "Load", callback = function() end })

Pass { direction = "column" } for a vertical group, which also takes dropdowns, sections, text and dividers.

Button

Main.Left:CreateButton({
    name = "Go To Work",
    callback = function()
        print("clicked")
    end,
})
OptionDescription
nameButton label.
descriptionOptional line under the button.
iconOptional asset id.
callbackRuns when clicked.

Toggle

local AutoFarm = Main.Left:CreateToggle({
    name = "Auto Farm",
    value = false,
    callback = function(enabled)
        print(enabled)
    end,
})

AutoFarm:Set(true)
print(AutoFarm.value)
OptionDescription
nameLabel.
valueStarting state (default false).
description, iconOptional.
flagSave key. Defaults to the name without spaces.
forgetStatetrue to never save it.
callback(value)Runs with the new state.

Slider

local WorkTime = Main.Right:CreateSlider({
    name = "Work Time",
    range = { 5, 120 },
    increment = 5,
    value = 30,
    suffix = "min",
    callback = function(value, dragging)
        print(value)
    end,
})

WorkTime:Set(60)
OptionDescription
range{ min, max }.
incrementStep size (default 1).
valueStarting value.
suffixText after the number, like "min" or "%".
minimalJust the bar, no label.
callback(value, dragging)dragging is true while held.

Dropdown

local Job = Main.Left:CreateDropdown({
    name = "Select Job",
    options = { "Baker", "Cashier", "Delivery" },
    value = "Baker",
    callback = function(option)
        print(option)
    end,
})

Job:Set("Cashier")
Job:Refresh({ "Baker", "Cashier", "Miner" }) -- replace the options
Job:Add("Janitor")
Job:Remove("Miner")

With multiSelect = true, value is a list and the callback gets a list.

Main.Left:CreateDropdown({
    name = "Modules",
    options = { "ESP", "Tracers", "Chams" },
    multiSelect = true,
    value = { "ESP" },
    placeholder = "None selected",
    callback = function(selected)
        print(table.concat(selected, ", "))
    end,
})

Input

Main.Left:CreateInput({
    name = "Player Name",
    placeholder = "Enter a name",
    callback = function(text)
        print(text)
    end,
})

numeric = true only allows numbers. clearOnFocus = true empties the box when clicked. The callback runs on Enter or when the box loses focus.

Keybind

Main.Right:CreateKeybind({
    name = "Sprint",
    value = Enum.KeyCode.LeftShift,
    callback = function(key)
        print("pressed", key)
    end,
})

-- hold mode: true when held, false when released
Main.Right:CreateKeybind({
    name = "Zoom",
    value = Enum.KeyCode.C,
    hold = true,
    callback = function(holding)
        print(holding)
    end,
})

Color Picker

Main.Right:CreateColorPicker({
    name = "Highlight",
    color = Color3.fromRGB(235, 90, 215),
    callback = function(color, alpha)
        print(color, alpha)
    end,
})

Accepts a hex string for color too. alpha (0–1) sets the starting opacity.

Stat

A card that shows a number and how much it changed.

local Earnings = Main.Right:CreateStat({
    name = "Shift Earnings",
    prefix = "$",
    value = 349,
})

Earnings:Set(Earnings.value + 50)

Options: prefix, suffix, compact (a smaller card), display = "change" (show the change instead of the value on a compact card), changeMode = "absolute" (show the difference instead of a percentage).

Progress

local Download = Main.Right:CreateProgress({
    name = "Download",
    range = { 0, 100 },
    value = 35,
})

Download:Set(80)
Download:SetText("Almost done")

Main.Right:CreateProgress({ name = "Setup", steps = 5, value = 2 })             -- segmented
Main.Right:CreateProgress({ name = "Loading", indeterminate = true })          -- endless sweep

Console

A scrollable text box for logs.

local Log = Main.Right:CreateConsole({
    name = "Console",
    height = 120,
    follow = true, -- stay scrolled to the newest line
})

Log:Append("[12:00] started")
Log:Clear()
Log:Copy() -- copies to clipboard where supported

Notifications

Window:Notify({
    title = "Saved",
    content = "Your settings were saved.",
    duration = 5,
    icon = 125823673784681,
})

duration is optional. Without it, the notification stays longer for longer text.

Toasts

A short message at the top or bottom of the screen.

Window:Toast({ title = "Heading to work" })
Window:Toast({ title = "Saved", subtitle = "Pulse", position = "Bottom" })

Popups

Window:Popup({
    title = "Reset everything?",
    content = "This can't be undone.",
    options = {
        { text = "Cancel" },
        { text = "Reset", style = "danger", callback = function()
            print("reset")
        end },
    },
})

Option styles: "neutral" (default), "primary", "danger".

Tags

Small badges next to the window title.

Window:CreateTag({ text = "Bloxburg", color = Color3.fromRGB(235, 90, 215) })

Locking

Buttons, toggles, sliders, dropdowns, inputs, keybinds and color pickers can be locked. A locked element dims, ignores input and never fires its callback.

AutoFarm:Lock("Needs a premium key")
AutoFarm:Unlock()
print(AutoFarm:IsLocked())

Saving & flags

Turn on configuration in CreateWindow and element values save automatically. Each element is saved under its flag, which defaults to its name without spaces ("Work Time" becomes WorkTime).

print(Window.Flags.WorkTime)   -- read any saved value
Window.Flags.WorkTime = 60      -- set it (updates the UI and runs the callback)

Window:Save("PvP")              -- save a named config
Window:Load("PvP")
print(Window:ListConfigs())

Files go in RayfieldColumns/Configurations. Players can also save and load configs from the settings page.

Theming

The Default theme is the only built-in theme. To change colors, pass a table with just the keys you want:

Window:ChangeTheme({
    AccentColor = Color3.fromRGB(235, 90, 215),
    SliderProgress = Color3.fromRGB(235, 90, 215),
})

Localization

Give translations keyed by language, using the English text as the key. Missing entries stay in English.

local Window = Rayfield:CreateWindow({
    name = "Pulse",
    translations = {
        fr = { ["Auto Farm"] = "Farm auto" },
    },
})

Window:SetLocale("fr")
